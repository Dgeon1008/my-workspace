# 모아 오목 프로젝트

- 원본은 `app/`에만 둔다. 모아는 같은 앱을 공유 실행기로 열며 UI·게임 로직 복사본을 만들지 않는다.
- `app`에서 `npm start`로 직접 실행한다. 기본 주소는 `http://127.0.0.1:4176`이며 기존 공유 서버가 있으면 재사용한다.
- 규칙은 15×15 자유룰이다. 흑 선공, 5개 이상 연결 시 승리, 금수 없음. 규칙을 바꾸면 안내와 엔진 테스트를 함께 수정한다.
- 승리·무승부·컴퓨터 수·저장 검증은 `app/engine.mjs`, 표시와 이벤트는 `app/game.js`, UI 스타일은 `app/style.css`에 둔다.
- 저장 기록은 수순으로 검증·재생한다. 저장된 승자·바둑판 배열을 신뢰하지 않는다.
- 모아 테마는 실행기가 전달하는 `html[data-moa-theme]`으로 받는다. 직접 미리보기는 시스템 테마를 따른다.
- 서버의 `createAppServer` 진입점을 유지한다. 저장하면 공유 실행기가 서버와 화면을 자동 갱신한다.
