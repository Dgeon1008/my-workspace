# 모아 2048 프로젝트

- 원본은 `app/`에만 둔다. 모아 메뉴는 이 프로젝트의 같은 앱 서버를 열며 별도 UI 사본을 만들지 않는다.
- `app`에서 `npm start`로 실행한다. 기본 주소는 `http://127.0.0.1:4177`이고 같은 공유 서버가 있으면 재사용한다.
- 4×4 보드, 숫자 합치기, 점수, 한 수 되돌리기, 계속하기 규칙은 `app/engine.mjs`에 둔다. 화면과 입력 처리는 `app/game.js`, 스타일은 `app/style.css`에 둔다.
- 현재 판과 되돌리기 한 수는 이 브라우저의 localStorage에 저장하고, 불러올 때 보드와 점수 형식을 확인한다. 최고 점수는 판 초기화와 별도로 보존한다.
- 모아 화면 모드는 실행기가 전달하는 `html[data-moa-theme]` 속성을 사용한다. 공유 실행기의 저장 감시가 파일 저장을 반영한다.
- 서버의 `createAppServer` 진입점과 안전한 정적 파일 제공 규칙을 유지한다.
