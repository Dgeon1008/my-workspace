# Craft Anything ↔ 모아 공유 프로젝트

- 이 폴더는 Craft Anything이 사용하는 원본 프로젝트다. 앱 코드는 `app/` 한 곳에서만 수정한다.
- 모아는 `app`의 원본 웹 앱을 내부 창에서 표시한다. 모아용 UI·게임 로직 복사본을 만들지 않는다.
- `app`에서 `npm start` 또는 `npm run dev`를 실행하면 공통 실행기와 파일 감시가 켜진다. 기본 주소는 `http://127.0.0.1:4175`다.
- 모아와 직접 미리보기에 같은 주소를 사용한다. `dist`는 빌드 결과이며 직접 수정하지 않는다.
- `app/server.mjs`의 `createAppServer()` 진입점을 유지한다. 소스 파일·새 파일·서버 의존성 변경은 공유 실행기가 감지하고 서버를 새 프로세스로 교체한다.
- 변경을 위해 모아의 화면 연결 파일이나 파일 허용 목록을 고칠 필요가 없다.
- 프로젝트 경로를 옮겨야 하면 루트의 `harness-projects.json`에 원본 경로를 함께 반영한다.
- 정적 빌드 결과만 보는 Craft 검사 화면과 실행 중인 앱은 구분한다. 실제 동작 확인은 공유 실행 주소에서 한다.
